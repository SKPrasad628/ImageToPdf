## Boundaries

This verifies that a complete copy served locally can import and export without internet-hosted runtime dependencies. It does not add a service worker or guarantee that a remotely hosted first visit, or reopening a hosted app while offline, will work without previously available application files. Browser-wide offline mode also prevents reaching a local HTTP server; the acceptance fixture instead blocks external origins.

Omission reports persist in the current tab and describe the captured export. They are not draft recovery across refresh or closure. The binary filter check covers one diagnostic recipe; automated tests cover recipe ownership, ordering, existing transforms, cancellation, failure, and undo. Blur fidelity, crop/resize issues, other browsers, physical-device input, and screen-reader acceptance remain in their own audit scope. No issue after 30 is completed by this pass.
